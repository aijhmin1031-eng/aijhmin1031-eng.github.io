- 발행 공정: `CLAUDE.md` / 기획·운영: `docs/운영계획.md` (Drive `SOSO_작업실_블로그`에 사본)

## 글 쓰는 법

`_posts/`에 `YYYY-MM-DD-슬러그.md` 파일 추가. front matter:

```yaml
---
layout: post
title: "제목"
date: 2026-08-21 10:00:00 +0900
lang: ko
image: /assets/og/슬러그.jpg   # 공유 카드 / thumb: 히어로
categories: 시작가이드
---
```

푸시하면 GitHub Pages가 자동 빌드·배포 (1~2분).

## 원칙

- 직접 해본 것만 쓴다. 비용·수수료는 숫자로.
- AI 사용 공시 문구를 글 말미에 유지.
- 개인정보(이메일·계정번호·주소)와 API 키는 절대 커밋하지 않는다.
- 특정 상점 홍보는 자연스러운 맥락에서만 (블로그의 신뢰가 우선).
