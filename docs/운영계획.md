## AdSense 승인 로드맵
1. **콘텐츠 15~20편 축적** (현재 6편: 한 3 + 영 3) — 승인 심사의 최대 변수
   - 한 편당 800자 이상, 직접 경험 기반, 이미지 1장 이상 권장
2. **필수 페이지** ✅ 완비: 소개(About)·개인정보처리방침(Privacy)·문의(Contact)
3. **도메인**: github.io 서브도메인으로도 신청 가능(퍼블릭 서픽스라 독립 사이트 취급)
   하나 승인율은 커스텀 도메인이 유리 — 글 15편 시점에 도메인 구매 검토 (~2만 원/년)
4. **신청**: adsense.google.com → 사이트 추가 → ads.txt·확인 코드는 repo에 커밋
5. **승인 후**: _config.yml의 google_adsense 주석 해제 + 광고 코드 삽입
